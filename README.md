# Tour booking site

Local tours: a catalogue with filters, a comparison table and a form that counts the price for the group.

**Live:** https://dmitrii-mazurkevich.github.io/tour-booking-website/

![Tour booking site](preview.png)

## Built with

HTML, CSS, JavaScript. Static site without a build step: open `index.html` or publish the folder to any hosting.
English and Russian versions with a language switcher, layout for phones and desktops.
